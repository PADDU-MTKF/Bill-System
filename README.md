# 🧾 Billing System Desktop App

A **simple and user-friendly desktop billing application** built using **Python and Tkinter**.  
This application allows users to **add items, generate itemized bills, view totals, and print or save the bill receipt**.

It is designed as a standalone **desktop utility** for small shops, billing counters, or point-of-sale workflows.

---

## ✨ Features

- Add multiple items with quantity & price  
- Automatic calculation of totals  
- Generates a formatted **bill receipt**  
- Save or print the bill  
- Simple GUI built with **Tkinter**  
- Easy to use  
- Clears the cart after generating bill

---

## 📌 Project Overview

This application focuses on fundamental billing operations:

1. Enter item details such as **name, rate, quantity**
2. Add items to the bill
3. Review the **generated bill**
4. Save or print the bill for record

This is a **local desktop app**, not web-based
